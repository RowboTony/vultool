# ⚠️ PROJECT DISCONTINUED

**This project has been discontinued in favor of official Vultisig tools.**

## Why?

The official Vultisig ecosystem now provides production-ready alternatives that supersede all vultool functionality:

- **[vultisig-cli](https://github.com/vultisig/vultisig-cli)** - Comprehensive Rust CLI with MPC signing
- **[vultisig-sdk](https://github.com/vultisig/vultisig-sdk)** - TypeScript SDK for developers  
- **[vultisig-share-decoder](https://github.com/vultisig/community-tools/tree/main/recovery-tools/vultisig-share-decoder)** - Web-based recovery tool

## For Users

**Please migrate to the official tools above.** They offer superior functionality, active maintenance, and production support.

## Repository Status

This repository will be archived as read-only for historical reference. All technical analysis and documentation remains available for educational purposes.
